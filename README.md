# 🎮 Basic Video Game Data Analysis

## 📌 Project Overview
This project focuses on analyzing video game data to understand trends, patterns, and insights using Python data analysis libraries.  
The analysis helps in exploring game sales, popularity, and other key factors through visualizations.

---

## 🛠️ Tools & Libraries Used
- **Python**
- **NumPy** – numerical operations
- **Pandas** – data cleaning and manipulation
- **Matplotlib** – data visualization
- **Seaborn** – advanced and attractive visualizations

---

## 📊 Features
- Data loading and preprocessing
- Handling missing values
- Statistical analysis of video game data
- Graphical visualization of trends using plots and charts
